# Circuit-Analysis-Tool
C++ circuit analysis tool that reads a netlist and computes node potentials, branch voltages, and branch currents using Modified Nodal Analysis (MNA).

# How to run
On powershell run the commands:
- g++ main.cpp Circuit.cpp Matrix.cpp -o ex1
- ./ex1
The first command compiles the necessary files which include the main.cpp, Circuit.cpp, and Matrix.cpp and creates an executable file called ex1.exe. 
The second command runs the created executible file (ex1.exe).
